我认为还有两个重要的区别：1、 从用户心智上，Cursor 是人和模型结对编程，而 Claude Code 更多的是模型自主完成编程目标，所以简化了人机操作界面，以命令行的形式提供给用户；2、 命令行对比 UI 界面有一个巨大的优势，可以放到机器上作为服务运行，能支持横向扩展，更接近 7x24 小时工作的 AI 员工。
